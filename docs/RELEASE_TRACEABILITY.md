## Rules for updating this file

1. Keep `VERSION`, the CHANGELOG heading, `candidate_version` here and the
   release gate in sync; the gate fails on a mismatch.
2. Every non-blocked work item must have at least one PR or commit link; a
   blocked item must explain its blocker.
3. PR entries need a number, an HTTPS `.../pull/<n>` URL and a 40-hex merge
   commit; commit entries need 7–40 hex characters.
4. `included_prs` is covered by the union of work-item PRs and `support_prs`.
5. Historical release facts are corrected through sourced amendments, never
   silently retargeted.
