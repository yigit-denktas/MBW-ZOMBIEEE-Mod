Integrity
- The pinned size/SHA-256 identity above is enforced by `tools/archive_audit.py` and
  `tools/build.py` before extraction or installation.
- A full member-CRC test requires 7-Zip. A Windows `7z t` run on 2026-10-23 was reported to pass all
  1,068 files (see [`docs/ENGINE.md`](../docs/ENGINE.md)); an older libarchive-based inspection could
  not decode 99 members and must never be used to install. Always re-run `7z t`/`build.py` with
  real 7-Zip before deploying.

Redistribution and handling
- The archive is owner-supplied and private. Never commit it, extract it into a tracked path,
  publish it, or bundle it with any release or diagnostic artifact.
- `tools/build.py` refuses to overwrite an existing install; back up before passing `--replace`.
- All extracted/built original assets stay local (`local/` and `evidence/` are gitignored). See
  [`docs/PROVENANCE.md`](../docs/PROVENANCE.md) §4 for the asset/evidence boundary.
